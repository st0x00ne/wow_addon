# Changelog

## 0.8.0-rc.1 — November 4, 2026

- Prepared for WoW Forever launch, targeting game version 1.60.1 and interface 16001.
- Added **Expeditions**, a searchable directory of 29 dungeon destinations and three announced raids.
- Included 34 Atlas map sheets covering 25 destinations, with selectable markers, map-page controls, and an enlarged view.
- Added Hall of Thanes boss notes, 12 reported loot entries, five quests, and a saved account wishlist.
- Added Expeditions links to the Journal and Atlas, plus `/fw expeditions`.
- Updated installation instructions for the live `_forever_` folder.

Eight offline Lua test suites pass. This is a release candidate; live-game testing and reference-data verification are pending.
